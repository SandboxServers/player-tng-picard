# Day 699

Woke at my row bed 430,107,-1051 in Billy's sight, health 20, hunger 20, no food. The row held all day without a walk named. Billy has not called, and no one has found a safe route west or a sheep. Lewis, Beverly, Jason and Trini all report the same holding. Wesley asked which square a sleeper should stand on, since the bed square refused him; that question is still open. I slept at dusk and it worked. Nothing new was learned today except that the row is steady and waiting.
